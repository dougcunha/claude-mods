## README contract
21:## ✨ What it does
23:The mod does not read the files of any flow. It registers 1 tool, `mcp__feature-progress__report`, and the flow calls it at each change of state. Any flow can report: SDD skills, other skills with other artifact names, or a prompt.
41:## 🚀 Install
55:Add the storage folder to the repository's `.gitignore`, unless you want the progress files in Git:
61:## 📣 Report progress from your flow
63:Tell the session that runs your flow to call `mcp__feature-progress__report` at each change of state. Only the main session reports; a call from a subagent is answered `Ignored: only the main session reports progress.` and stores nothing. A skill that reports should skip the step when the tool is not there, so the flow also runs without the mod.

143:### The stored file
145:`<folder>/<id>.json` holds `schemaVersion` (1), the feature fields, its timestamps and `tasks`. A file the mod cannot read as a feature (broken JSON, another `schemaVersion`, a missing field, or a name that is not `<id>.json`) shows as a warning row in the pane, and a report for that id is refused until you fix or delete the file. A report reads the file before it writes, so it keeps what another session wrote since this session last read the folder.
